# 豆包海报生成工作流 · V6.1.0

## 核心判断

豆包并不要求所有海报都提供模板图。真正稳定的产品路径应当区分：

1. 干净无字底图；
2. 留白后期排字；
3. 无字海报骨架；
4. 指定短标题参与构图；
5. 附带模板图的复杂海报。

## 新增策略：poster-layout

`poster-layout` 的目标不是“空出一块区域”，而是让底图本身已经具有平面设计秩序：

- 一个明确主标题容器；
- 一个底部信息带；
- 一到两个辅助图形层；
- 可控的前后穿插、遮挡边界或色块节奏；
- 完整保护眼睛、鼻梁、嘴部、颈部与关键手势；
- 不生成实际文字、字母、数字、占位文案与伪文字。

## 模板参考图规则

### none

不依赖模板，严格按内置海报骨架执行。

### recommended

默认模式。无模板也能执行；复制出的 Prompt 会说明：如额外上传模板图，只参考版式结构，不复制人物和文字。

### attached

明确声明最后一张上传图片为版式模板参考，仅提取：

- 海报骨架；
- 主体锚点；
- 标题容器比例；
- 留白位置；
- 图层前后关系；
- 色块节奏；
- 印刷肌理。

禁止复制模板中的人脸、品牌、可读文字、Logo、水印与具体内容。

## 商业交付建议

准确标题、姓名、日期、学校、品牌与活动信息，仍应进入 PVOS 排版工作区叠加。生图模型负责视觉结构，排版层负责准确交付。
