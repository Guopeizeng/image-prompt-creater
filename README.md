# PVOS V6.1.1 · Poster Structure Runtime

项目主页：<https://github.com/Guopeizeng/image-prompt-creater>

## Windows 启动入口

完整解压后，优先双击根目录下的 `00_START_PVOS_SAFE.bat`。它是 Windows 兼容修复后的安全入口。

- 启动：`00_START_PVOS_SAFE.bat` 或 `START_PVOS.bat`
- 停止：`STOP_PVOS.bat`
- 后台：`OPEN_ADMIN.bat`

原有中文文件名入口仍然保留，但英文入口更适合不同 Windows 区域设置。

本包是 Portrait Visual OS 的本地轻量运行时。

- 用户侧构建：`V6.1.1 Poster Structure Runtime · 2026-06-12`
- 封板视觉 Core：`5.16.1 sealed library`
- 模型接入状态：**仅生成 Prompt，不直连 GPT、豆包、即梦或其他外部模型 API**

## V6.1.0 解决的问题

旧版简单面板中的“海报结构参与”在没有填写标题时，会静默降级为“留白后期排字”。豆包实际收到的是一张普通人像底图指令，而不是海报指令。

V6.1.0 新增第六种底图策略：

```text
poster-layout
```

它专门用于：**生成真正可见的无字海报骨架，同时将准确文字留给后期排版层。**

无论是否填写标题，海报路线都不会再静默退回普通留白写真。

## 三种常用工作流

### 1. 干净无字底图

适合写真、街拍、纪实、校园与婚礼抓拍。

```text
干净无字底图
→ 豆包只负责人物、环境与光线
→ 排版工作区后期叠字
```

### 2. 海报结构参与，不填写标题

适合复杂海报，希望先获得完整平面结构，但避免豆包生成乱码。

```text
海报结构参与
→ 标题留空
→ 编译为 poster-layout
→ 豆包生成主标题容器、底部信息带、辅助色块、边界线与图层关系
→ 不渲染实际文字、字母、数字、占位文案或伪文字
→ 排版工作区叠加准确文字
```

### 3. 海报结构参与，填写标题

适合一个短标题直接参与画面，例如“我们万岁”。

```text
海报结构参与
→ 填写短标题
→ 编译为 integrated-text
→ 豆包尝试将该标题作为唯一刻意出现的文字元素
→ 排版工作区继续保留准确文字层用于校正
```

## 版式模板图不是必选项

V6.1.0 在简单面板中新增三档“版式模板图”规则：

| 模式 | 使用场景 | 行为 |
|---|---|---|
| 自动建议 | 默认 | 无模板也能运行；复杂拼贴、旧刊、多层海报建议额外上传模板 |
| 不用模板 | 极简封面、普通海报 | 严格按系统内置海报骨架生成 |
| 已附模板图 | 撕纸拼贴、旧刊、票根、巨字、多画格 | 提示词声明最后一张上传图片仅用于参考版式骨架 |

选择“已附模板图”时，请按以下顺序上传到豆包或即梦：

```text
图 1 至图 N：人物身份参考
最后一张图：版式模板参考
```

模板图只用于提取：主体锚点、标题容器比例、留白位置、图层前后关系、色块节奏和印刷肌理。Prompt 会明确禁止复制模板中的人物、品牌、可读文字、Logo 和水印。

## 核心能力

```text
选择风格
→ 绑定真实 canonical route
→ 选择 GPT 或豆包提示词适配
→ 选择紧凑 / 标准 / 丰富导演版
→ 选择底图、留白或海报骨架模式
→ 可选：声明版式模板图规则
→ 生成 Prompt
→ 复制到目标生图工具
→ 上传生成结果
→ 成品排版
→ 导出 PNG
```

GPT 丰富导演版约 1900–2100 词。豆包线使用自然中文强约束结构。

## 提示词适配成熟度（V6.1.1 新增）

| 适配线 | 成熟度 | 用途 | UI 标记 |
|---|---|---|---|
| GPT 生图（`gpt-image`） | **主线**（`stable`） | 当前唯一相对完善的主线，推荐日常使用 | 默认高亮，无角标 |
| 豆包 Seedream（`doubao-seedream`） | **测试版**（`test`） | 中文整句强约束结构仅做基础编译，欢迎试用但**不要作为唯一交付路径** | 按钮带橙色“测试版”角标，选中后显示明确警告条 |

选择豆包线时，工作台会强制显示如下说明：

> 豆包线当前为测试版本：豆包线使用自然中文强约束结构，仅做基础编译，尚未与 GPT 提示词同等打磨；可试用，但不要把它作为唯一交付路径。

未来如豆包线达到与 GPT 同等质量，需在 `library/provider_profiles.json` 中将 `maturity` 改为 `stable`，并经 parity audit 后再发布新版本。

## 隐私与本地文件

本地运行会创建：

```text
.venv/
data/
uploads/
private_assets/
logs/
```

这些目录只服务于当前电脑，不应上传到公开仓库或发送给他人。匿名统计默认关闭，可在界面中主动开启。

## 旧服务占用 4173 端口时

多个历史版本共享封板视觉 Core `5.16.1`。旧启动器只检查 Core 版本，可能误把旧服务当作当前服务。
本版本会额外检查：

```text
runtime_build = V6.1.1
ui_build = v6101-20260612
```

检测到旧版 PVOS 时，会明确提示停止旧服务后再启动当前版本，不会静默打开旧页面。
